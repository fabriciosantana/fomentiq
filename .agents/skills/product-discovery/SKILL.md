# Product Discovery

1. Read `PROJECT_CONTEXT.md`, `PRODUCT_VISION.md`, `PERSONAS.md`, `JOBS_TO_BE_DONE.md`, `USER_JOURNEYS.md`, `PRODUCT_REQUIREMENTS.md` and `MVP_SCOPE.md` as relevant.
2. Identify which user, job and outcome the requested change serves.
3. State whether the request is inside the current MVP.
4. If outside MVP, do not silently implement it. Recommend backlog placement or an explicit scope change.
5. Separate problem, desired outcome and proposed solution.
6. Update product artifacts only when the decision is durable.
7. For behavior changes, hand off to the OpenSpec workflow after product intent is clear.

Output should be concise: decision, rationale, impacted artifacts, acceptance signal.
